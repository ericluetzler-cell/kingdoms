# Kingdoms

Ein Strategiespiel für den Browser: Erobere Provinzen, erforsche Technologien, führe Divisionen in die Schlacht – gegen KI-Herrscher oder online gegen Freunde.

**Spielen:** Einfach die Seite öffnen. Für ein Online-Spiel erstellt eine Person einen Raum und schickt den Code oder Link an die anderen.

Läuft komplett im Browser (HTML, CSS, JavaScript), ohne eigenen Server. Online-Räume verbinden die Spieler direkt per WebRTC (PeerJS).
